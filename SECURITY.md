# Security

Eidryl runs explicitly trusted local Python factories. It does not sandbox an imported module, reverse its external side effects or isolate CPU/network/filesystem access. Only use targets you control and trust.

Portable imported models are data executed by a fixed bounded grammar. They may contain incorrect or intentionally misleading predictions. Imported or recorded evidence is unsigned and is not independent authentication.

Report a vulnerability privately through this repository's GitHub security reporting channel. Include the affected version, the smallest relevant model/request, expected boundary and observed behavior. Do not include credentials or private target data.
